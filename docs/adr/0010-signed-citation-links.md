# ADR-0010 — Source links in Telegram are short-lived signed URLs bound to the employee

- Status: accepted
- Date: 2026-10-22
- Related: ADR-0004, ADR-0005, ADR-0009, DOMAIN_CONTRACT §5 (`/s/doc/*`), §14

## Context

The idea requires the bot to attach a link to the source document. `/knowledge/{document}/download`
sits behind a web session, and `telegram_only` employees have no session. A public URL would leak
documents outside department/role ACL.

## Decision

1. Citation and `open_source` links are Laravel temporary signed routes, **TTL 30 minutes**, bound to
   `user_id` and `document_id`:
   `GET /s/doc/{document}?u={user_id}&c={chunk_id?}&p={page?}&expires=…&signature=…` (route name
   `share.document`). Generated by web when the worker logs the answer (`POST /internal/v1/ai-queries`
   returns signed URLs per citation) — the ai service only returns `{document_id, chunk_id, page}`.
2. On open, web re-checks everything at that moment: signature and expiry; user `active` in the
   document's workspace; `visible(doc, user)` (ADR-0009); document `approved` and not archived.
   - Expired → localized page "This link has expired — ask the bot again" (HTTP 403).
   - Archived and superseded → page with title + "This regulation was replaced" + link to the successor
     only if the successor is visible to the same user (re-signed, same TTL).
3. The page `share/DocumentViewer` is a minimal, localized (user's locale), themed (system preference +
   toggle) viewer without the app shell: title, version, effective date, department chips, the cited
   section highlighted (`<mark>` styled with the `--highlight-sun` tokens) with ±1 neighbouring chunks
   (from ai `GET /v1/documents/{id}/chunks/{chunk_id}?workspace_id=&context=1`), and a "Download
   original" button (signed, TTL 5 min, same checks).
4. Every successful open is audited as **`document.viewed_via_bot`** (actor = the bound user,
   subject = document, metadata `{chunk_id, page, version}`), throttled to one entry per user/document
   per 10 minutes.
5. Response headers: `Cache-Control: private, no-store`, `X-Robots-Tag: noindex, nofollow`,
   `Referrer-Policy: no-referrer`; the CSP stays `default-src 'self'`.

## Consequences

- A forwarded link works for at most 30 minutes and is attributable to the employee who received it —
  stated in the employee notice (ADR-0015) and accepted as residual risk (PLAN risk R7).
- Telegram rejects `localhost` URLs in inline keyboards; in dev the link is in the message text and the
  fake transport captures the keyboard unchanged. The worker keeps URL buttons only for public
  `http(s)` URLs (foundation `isPublicHttpUrl`), otherwise renders the link inline.

## Alternatives considered

- **"Get file" button → `sendDocument` through the company bot** after an ACL check: simpler for
  employees, but the file then lives in Telegram forever and leaves our retention control. Deferred to
  v1 as an opt-in workspace setting.
