# Keys and access cards

Applies to: residential cleaning team. Template — adapt to your company before approving.

## Receiving keys

- Accept client keys only against a signed key receipt (form KH-1).
- Every set of keys goes into a sealed numbered key bag. Never write the client address on the keys
  or on the bag; use the code tag only (for example K-0457).

## Keeping keys

- Keys stay with you only during the visit day. Never hand keys to anyone else, including neighbours,
  the concierge or another cleaner, unless the client gave written instructions.

## Returning keys after the last visit

- Return the client keys to the dispatcher within 24 hours after the last visit and sign the return in
  the key register.
- If the client asks to leave the keys inside the apartment, do it only with a written message from the
  client and send a photo of the keys on the table.

## Lost keys

Report lost keys to your manager immediately, within 15 minutes, by phone and in the bot (incident
category "Other"). The manager decides whether the lock must be changed.
